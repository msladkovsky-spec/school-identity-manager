# School Identity Manager

Multi-tenant SaaS aplikace pro správu žákovských účtů v Microsoft 365.

## Cíle

- Zakládání žákovských účtů
- Hromadný import z Excelu
- Správa licencí
- Správa skupin
- Povyšování ročníků
- Archivace absolventů
- Auditní log

## Technologie

- Microsoft Entra ID
- Microsoft Graph
- Azure Functions
- Azure SQL
- Application Insights

## Stav projektu

MVP
